# Steel-ML-Research

## Physics-Informed Machine Learning for Interpretable Prediction of Steel Mechanical Properties

This repository contains research outputs, figures, tables, and analysis files for a machine-learning study of steel mechanical properties.

## Research Objectives

- Develop and evaluate machine-learning approaches for predicting steel mechanical properties from composition-related features.
- Investigate the contribution of physical and metallurgical descriptors to model predictions.
- Use SHAP analysis to interpret feature contributions.
- Examine model reliability and the effect of physics-informed features through dedicated analyses.

## Dataset and Prediction Targets

The study uses a steel-composition dataset containing 312 compositions and 13 elements. The prediction targets are yield strength, tensile strength, and elongation. Confirm these details against the final dataset before publication.

## Methods

The project includes XGBoost and Random Forest modelling, interpretable feature analysis, physics-informed descriptors, reliability analysis, and feature-ablation analysis. The exact methods and results should be interpreted using the corresponding files in this repository.
